# Game artwork

Place transparent symbol PNGs in `icons/` using these filenames:

- `A.png`, `K.png`, `Q.png`, `J.png`, `10.png`
- `M.png` for the multiplier and `L.png` for level-up

Place optional lobby cover art at `images/cascades-slots.png` (6:5 aspect ratio).

The slots screen uses `images/slots_background.png` as a window-filling backdrop. The app scales and crops it in memory.

Restart the app to preview new artwork. Missing symbol images use letter tiles.
